Kế hoạch deploy

Đưa game lên https://elvion.io.vn bằng một máy ảo Compute Engine e2-micro (gói Free Tier của Google Cloud) chạy đúng compose.yaml hiện có. Người chơi vào qua Cloudflare Tunnel, máy ảo không mở cổng web nào.

Điều kiện chặn: phải xử lý trước khi bắt đầu
  • Thanh toán Google Cloud chưa xong. Trang Welcome đang báo "Your Free Trial is pending · Prepayment is needed". Compute Engine (kể cả e2-micro miễn phí) chỉ chạy khi project đã gắn tài khoản thanh toán đang hoạt động. Bạn phải tự bấm Make a payment; khoản trả trước được cộng thành tín dụng, không phải phí.
  • Tên miền phải chuyển DNS về Cloudflare. Cloudflare Tunnel với tên miền riêng yêu cầu thêm elvion.io.vn vào Cloudflare (gói Free) và đổi nameserver tại nơi đăng ký tên miền. Cần thử ngay ở bước 1, vì cần xác nhận Cloudflare gói Free có nhận tên miền đuôi .io.vn hay không. Nếu không nhận, kế hoạch phải đổi.

Sơ đồ

  • Người chơi chỉ nói chuyện với Cloudflare. Container tunnel chủ động mở kết nối ra ngoài tới Cloudflare, nên máy ảo không cần nhận kết nối từ Internet.
  • app và db giữ nguyên như bản chạy trên máy bạn. Chỉ khác ở file compose.prod.yaml (bước 6): tunnel dùng token của tên miền thay cho địa chỉ trycloudflare ngẫu nhiên, và mỗi container có giới hạn RAM.
  • Bạn quản trị máy qua Cloud Shell (dòng lệnh gcloud trong trình duyệt, không phải cài gì trên Windows). SSH chỉ mở cho dải IP của IAP, Google xác thực tài khoản trước.

Cấu hình Free Tier

Free Tier của Compute Engine gồm: 1 máy e2-micro chạy liên tục mỗi tháng ở us-west1, us-central1 hoặc us-east1; 30 GB-tháng đĩa standard; 1 GB lưu lượng ra mỗi tháng từ Bắc Mỹ. Điều khoản có thể thay đổi, xem lại trang Free Tier của Google trước khi tạo máy.

Bộ nhớ: máy chỉ có 1 GB RAM

Hệ điều hành và Docker dùng khoảng 250–300 MB, phần còn lại chia cho 3 container. Thêm 2 GB swap để lúc build image (npm ci) hoặc lúc tải cao không bị hệ điều hành tắt bớt tiến trình. Đặt vm.swappiness=10 để chỉ dùng swap khi thật sự thiếu RAM, vì đĩa standard chậm.

ContainerGiới hạn RAMTinh chỉnh thêm
db256 MBshared_buffers=32MB, max_connections=20 (app dùng tối đa 10), work_mem=2MB, effective_cache_size=128MB
app256 MBNODE_OPTIONS=--max-old-space-size=160 để Node dọn bộ nhớ trước khi chạm giới hạn
tunnel128 MBKhông cần

Tổng tối đa 640 MB, còn chỗ cho hệ điều hành. Container nào vượt giới hạn sẽ bị khởi động lại nhờ restart: unless-stopped, không kéo sập cả máy.

Các bước deploy

Mọi lệnh gcloud chạy trong Cloud Shell (biểu tượng >_ góc trên bên phải Google Cloud Console). Lệnh trong máy ảo chạy sau khi SSH vào. Mỗi bước chỉ làm tiếp khi phần "Kiểm tra" đạt.

Bước 0 · Chuẩn bị

  • Đã thanh toán trả trước, trang Billing báo tài khoản đang hoạt động.
  • Có tài khoản Cloudflare (gói Free) và quyền đổi nameserver của elvion.io.vn.
  • Code mới nhất đã push lên GitHub (thanh-seo162/vibecode), hoặc có sẵn file nén để tải lên.
  • Đã sinh mật khẩu mới cho database và trang admin, không dùng lại mật khẩu trong .env trên máy bạn.

Bước 1 · Đưa tên miền về Cloudflare

  1. Cloudflare Dashboard → Add a domain → nhập elvion.io.vn → chọn gói Free.
  2. Cloudflare đưa 2 nameserver. Vào trang quản lý tên miền ở nhà đăng ký, thay nameserver cũ bằng 2 nameserver này.

Kiểm tra: trang tên miền trên Cloudflare báo Active (có thể mất vài giờ). Hoặc chạy lệnh dưới, kết quả là 2 nameserver của Cloudflare:

nslookup -type=NS elvion.io.vn

Bước 2 · Project, thanh toán và cảnh báo ngân sách

gcloud projects create dap-chuot-khoa-hoc --name="Dap Chuot"
gcloud billing accounts list
gcloud billing projects link dap-chuot-khoa-hoc --billing-account=MA_TAI_KHOAN
gcloud config set project dap-chuot-khoa-hoc
gcloud services enable compute.googleapis.com iap.googleapis.com

Tạo cảnh báo ngân sách trong Console: Billing → Budgets & alerts → Create budget, số tiền 1 USD, gửi email ở mức 50%, 90%, 100%.

Kiểm tra: gcloud billing projects describe dap-chuot-khoa-hoc có dòng billingEnabled: true. Trang Budgets có ngân sách 1 USD.

Bước 3 · Tường lửa và máy ảo

# SSH chỉ qua IAP; xoá luật mặc định mở cho cả Internet
gcloud compute firewall-rules create allow-ssh-iap \
  --network=default --direction=INGRESS --allow=tcp:22 \
  --source-ranges=35.235.240.0/20 --target-tags=dap-chuot
gcloud compute firewall-rules delete default-allow-ssh default-allow-rdp --quiet

# Máy ảo Free Tier
gcloud compute instances create dap-chuot \
  --zone=us-central1-a --machine-type=e2-micro \
  --image-family=debian-12 --image-project=debian-cloud \
  --boot-disk-size=30GB --boot-disk-type=pd-standard \
  --tags=dap-chuot --shielded-secure-boot

Kiểm tra:

gcloud compute instances describe dap-chuot --zone=us-central1-a \
  --format="value(machineType.basename(),status)"        # e2-micro  RUNNING
gcloud compute disks describe dap-chuot --zone=us-central1-a \
  --format="value(type.basename(),sizeGb)"              # pd-standard  30
gcloud compute firewall-rules list --format="table(name,sourceRanges.list(),allowed[].map().firewall_rule().list())"

Danh sách tường lửa không còn luật nào mở cổng 22 hoặc 3389 cho 0.0.0.0/0.

Bước 4 · Vào máy, thêm swap, bật cập nhật bảo mật

gcloud compute ssh dap-chuot --zone=us-central1-a --tunnel-through-iap

Trong máy ảo:

sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
echo 'vm.swappiness=10' | sudo tee /etc/sysctl.d/99-swap.conf
sudo sysctl --system

sudo apt-get update
sudo apt-get install -y unattended-upgrades git

Kiểm tra: free -h có dòng Swap: 2.0Gi; cat /proc/sys/vm/swappiness ra 10.

Bước 5 · Cài Docker

Cài từ kho chính thức của Docker cho Debian:

sudo apt-get install -y ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/debian/gpg -o /etc/apt/keyrings/docker.asc
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] \
https://download.docker.com/linux/debian $(. /etc/os-release && echo $VERSION_CODENAME) stable" \
  | sudo tee /etc/apt/sources.list.d/docker.list
sudo apt-get update
sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo usermod -aG docker $USER     # thoát SSH rồi vào lại để có hiệu lực

Kiểm tra: sau khi vào lại, docker run --rm hello-world in "Hello from Docker!"; docker compose version chạy được; systemctl is-enabled docker ra enabled.

Bước 6 · Tạo tunnel cho tên miền, đưa code lên

  1. Cloudflare Dashboard → Zero Trust → Networks → Tunnels → Create a tunnel → loại Cloudflared → tên dap-chuot. Chép token (chuỗi dài sau --token). Bỏ qua phần hướng dẫn cài đặt, vì cloudflared đã chạy trong Docker.
  2. Tab Public Hostname → thêm: hostname elvion.io.vn, service HTTP, URL app:3000. Cloudflare tự tạo bản ghi DNS.
  3. Trong máy ảo, lấy code: 
    git clone https://github.com/thanh-seo162/vibecode.git dap-chuot
cd dap-chuot
    Nếu repo riêng tư: nén code trên máy bạn, tải lên Cloud Shell (menu ⋮ → Upload), rồi gcloud compute scp vào máy ảo.
  4. Tạo .env (chỉ chủ sở hữu đọc được): 
    cp .env.example .env
chmod 600 .env
nano .env
    Đặt POSTGRES_PASSWORD và ADMIN_PASSWORD mới (sinh bằng openssl rand -base64 24), giữ COOKIE_SECURE=1, TRUST_PROXY=1, và thêm dòng TUNNEL_TOKEN=….
  5. Tạo compose.prod.yaml cạnh compose.yaml. File này nên được commit vào repo trước khi deploy: 
    # Ghi đè cho máy ảo: tunnel theo tên miền + giới hạn RAM.
# Chạy: docker compose -f compose.yaml -f compose.prod.yaml up -d --build
services:
  db:
    mem_limit: 256m
    command: >
      postgres -c shared_buffers=32MB -c max_connections=20
               -c work_mem=2MB -c effective_cache_size=128MB
  app:
    mem_limit: 256m
    environment:
      NODE_OPTIONS: --max-old-space-size=160
  tunnel:
    mem_limit: 128m
    command: tunnel --no-autoupdate run
    environment:
      TUNNEL_TOKEN: ${TUNNEL_TOKEN:?Thiếu TUNNEL_TOKEN trong .env}

Kiểm tra: ls -l .env hiện quyền -rw-------; docker compose -f compose.yaml -f compose.prod.yaml config -q không báo lỗi.

Bước 7 · Chạy

docker compose -f compose.yaml -f compose.prod.yaml up -d --build

Lần build đầu có thể mất vài phút vì máy yếu.

Kiểm tra trong máy ảo:

docker compose ps                                   # db, app: healthy; tunnel: Up
docker compose logs tunnel | grep -i "registered"   # có dòng "Registered tunnel connection"
docker stats --no-stream                            # mỗi container dưới giới hạn RAM
free -h

Trang Tunnels trên Cloudflare báo tunnel dap-chuot ở trạng thái Healthy.

Bước 9 · Sao lưu định kỳ

docker exec dap-chuot-db sh -c 'pg_dump -U "$POSTGRES_USER" "$POSTGRES_DB"' > backup-$(date +%F).sql

Mỗi tuần một lần, tải file về máy bạn (gcloud compute scp sang Cloud Shell, rồi menu ⋮ → Download). Không dùng snapshot đĩa vì bị tính phí.

Kiểm tra: file có dòng CREATE TABLE public.players và kích thước lớn hơn 0.

Cập nhật code về sau

cd ~/dap-chuot && git pull
docker compose -f compose.yaml -f compose.prod.yaml up -d --build --force-recreate app

Xoá sạch sau khoá học

  1. Sao lưu nếu cần giữ dữ liệu: chạy bước 9 lần cuối và tải file về. Sau bước 2 không khôi phục được.
  2. Xoá cả project (xoá máy, đĩa, IP, tường lửa cùng lúc): 
    gcloud projects delete dap-chuot-khoa-hoc
    Project chuyển sang chờ xoá 30 ngày rồi mất hẳn, tài nguyên ngừng tính phí ngay. Nếu đã dùng My First Project thay vì project riêng, xoá từng thứ: 
    gcloud compute instances delete dap-chuot --zone=us-central1-a   # đĩa khởi động bị xoá theo
gcloud compute firewall-rules delete allow-ssh-iap
  3. Cloudflare: xoá tunnel dap-chuot (Zero Trust → Tunnels), xoá bản ghi DNS của elvion.io.vn, xoá ứng dụng Access nếu có.
  4. Đóng tài khoản thanh toán nếu không dùng Google Cloud nữa: Billing → Account management → Close billing account.

Kiểm tra: gcloud projects list không còn project (hoặc hiện DELETE_REQUESTED); gcloud compute instances list, disks list, addresses list đều rỗng; vài ngày sau Billing → Reports không có chi phí mới.
